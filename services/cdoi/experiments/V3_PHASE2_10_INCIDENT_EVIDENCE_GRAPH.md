# V3 Phase 2.10 Incident Evidence Graph

Demo graph: 1 INCIDENT, 3 ENTITY, 2 EVENT, 2 CHANGE, 7 METRIC_OBSERVATION, and 12 TRACE_SPAN nodes. It contains 54 edges: 2 static relations, 3 trace parent-child edges, and typed incident/ownership edges. The archived graph is experiments/archive/v3_phase2_10/INCIDENT_EVIDENCE_GRAPH.json.

Static relation and trace parent-child edges remain different edge types. No graph edge is causal.
