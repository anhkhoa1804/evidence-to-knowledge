# The Edge Cases of Intelligent Knowledge Systems

*Retrieval, Reasoning, and Trust in Enterprise AI*

A six-part English blog series. It is a synthesis of published research on where retrieval-based knowledge systems for organisations stop working as advertised: graphs, incomplete knowledge, conflicting knowledge, schema-aware agents, agentic retrieval, and what trust means for the whole. It reports no experiments, builds no datasets, and uses no organisation's system as a case study. Every number is one a cited paper reports, in that paper's setup, or is marked as arithmetic on such numbers.

## Reading order

1. The Graph Is a Bet, Not an Upgrade
2. The Edge That Isn't There
3. Claims, Not Documents
4. Maps Before Walking
5. When to Stop Searching, and What It Costs
6. Trust Is Not a Component

Each part names an assumption, shows where the research says it breaks, and hands off to the next. Read in order; Part 6 draws on all the others.
